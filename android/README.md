# Dora64-3 for Android

Dora64-3 supports Android 7.0/API24 or newer, ARM64 and Vulkan1.0.

Install the release APK and select your own Japanese N3DJ revision0 `.z64`
ROM using the system file picker. The application checks and imports the ROM
into its own storage. The original file is preserved. The ROM is not included.

The gear opens settings. The Touch tab lets you edit the on-screen control
layout. Modern uses Manual60 FPS; Original preserves the original frame rate.
Physical gamepads and four player assignments are supported.

Application ID: `com.n64recomp.dora64three`. Settings and saves use this
application's storage. Keep the same signing key for updates.

See [the user guide](../docs/user-guide.md) for controls and saves,
[the build guide](../docs/building.md#android) for SDK requirements, release
signing and APK generation, and [release notes](../docs/release-notes.md).
