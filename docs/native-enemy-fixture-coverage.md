## Огненная цепочка: исправление Native после связанного replay

В kind372 при60FPS освобождение первого kind373 после собственного входа
через Source E7F54/E7528 меняло слот80 уже обработанного владельца.
Проверка Native принимала это обслуживание связи за внешнюю команду,
повторяла FSM владельца и увеличивала счётчик34 лишний раз. Та же
причина затрагивала последующие звенья373. Наблюдалось строгое
расхождение3 счётчиков на100ms, без расхождения аллокаций/моделей/команд.

Для точного ROM121280 и kind370/372/373 Source-managed массив дочерних
слотов исключён из признаков внешней команды. Сам FSM по-прежнему

счётчики, флаги и lifetime владельца остаются проверяемыми. Это правка
игрового Native, а не изменение исходного oracle или ослабление
сравнения RDRAM. Локальная проверка kind372 после правки: все48 сценариев PASS. Полный218-kind replay и все зависимые проверки PASS043.
