# Точные границы читаемых регистров

Каталог использует исключённый end. Новые области, записанные авторскими
helpers как последний безопасный instruction, уточнены до первого следующего
изменения/вызова. Реальная последняя pointer read остаётся в области; следующий
результат регистра туда не попадает. Области без единого реального обращения
не создают фиктивных имён и удалены. ctx storage и Source C не изменены.
Неудачная generation360 сохранена; следующая попытка отдельная361.

Итог: успешная generation361; строгие ROM proofs, канонические C tokens,
компиляция и5305 scoped variable names проверены штатным names check.
