# IgaHead325, Tutaru326, Butterfly374–376, Sakana377–378, Thunder379–381

В основной runtime внесены полные Source closure пяти семейств, включая
родительский генератор, warning и spark молнии, real model animation,
constructors/contacts/retirement. Native math продолжает IgaHead turnback,
Tutaru pitch/exponential shrink, Butterfly height, Sakana heading/speed и
Thunder opacity. RNG, direction choices, threshold/animation-end queries,
births, Source snap/floor setters и эффекты остаются исходными командами.

Butterfly height — зависимость от настоящего SH34±5, а не generic pose lerp;
ceiling selection сохраняет свой literal setter. Sakana shortest-angle
exponential heading продолжен также в XZ displacement. Shared home atan store
исключён из математической recurrence. Warning380 порождает sparks381 после
собственного model-group end; generator379 выполняет свои80-frame решения.
