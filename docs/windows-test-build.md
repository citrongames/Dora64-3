## test131: сборка частей и устойчивое волнообразное движение

Пользователь уточнил: «20 FPS» означает ступенчатое движение при Manual,

приводится к эквивалентной для целых Source-шагов области [-pi,pi], а около
нуля отношение и производная вычисляются устойчивым рядом. Поправка общая
для всех использующих эту формулу движений. Source-концы периода сохраняют
реальные ROM-значения; Original этим путём не проходит. Вращение самой
модели не ограничивается: нормализуется частота суммы перемещений.

сумму. Статически сверены167 обычных float-stores семейств боссов: неверных
