# Промежуточная сборка test-028

Полный перевод FPS ещё не завершён. Эта сборка сохраняется как результат
компиляции; запуск и ответ по ней сейчас не запрашиваются.

Исправлено копирование CPU-регистров в дополнительных кадрах и анимации:
внутренний указатель теперь относится к копии, а не исходному контексту.
Добавлен общий барьер перед заменой игровых callbacks: дождаться завершения
чтения обоих кадров и сохранить порядок остальных сообщений игровой очереди.

В код включены общая шкала непрерывного/дискретного времени, проверяемые
правила скорости, сценарная камера, прямоугольный 2D-переход и плавное
приближение камеры. Эти компоненты проверены отдельно на оригинальных функциях;
они ещё не включают частый update всего игрового процесса.

Живой Manual пока сохраняет прежний допуск: scene34 image/white fade.
Остальные сцены сохраняют исходную частоту без RT64 interpolation в Manual.
Обычная игровая камера, движение со столкновениями, остальные 2D-системы и
миниигры требуют продолжения интеграции. Original сохраняет исходный режим.

ROM только рядом с EXE. Настройки port_*.json и saves общие, журналы раздельные.
Упаковка не изменяет ROM или сохранения. Игра и renderer локально не запускались.
