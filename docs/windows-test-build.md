# Windows test-126

## test126: колёса, призраки и лента парка Дез

На базе принятого test125 / main1432c9b. Разбор реальных размещений ROM:
комната209 содержит Wheel1/2 (562/563) и шесть Derorin3 (310).

- Орбита призраков: восстановлены исходные X=cos(phase)*sin(heading),
  Y=sin(phase), Z=cos(phase)*cos(heading), радиус300. Ранее Native перепутал
  sin/cos и оси, поворачивая плоскость орбиты и нарушая её согласование
  с исходными конечными координатами. Счётчик/ИИ и Original сохранены.
- Оба колеса: добавлено пропущенное уравнение actor+14, +2 градуса,
  ROM14D4C0 / 8023ECCC. Gondola564 уже вычисляет настоящую матрицу
  родителя на дробном шаге; теперь получает плавный угол. Перенос игрока
  C0084/BFE60 и геометрия столкновений используют текущую позицию платформ.
- Тени: общий draw BB470→BD860→BD5D0 каждый показанный кадр берёт
  текущие XYZ призрака, запрашивает землю и заново вычисляет позицию,
  размер/прозрачность тени. Отдельного Source-счётчика в этом пути нет;
  тень следует исправленной орбите, дополнительной подмены не требуется.
- Лента F4: Source каждый grounded кадр повторно ставит clip5 с time0,
  затем SDK вычисляет позу ДО прибавки времени. Native между этими
  сбросами показывал короткий повторяющийся кусок анимации. Добавлен
  узкий render-only hold начальной позы для state61/F4/clip5/grounded
  при launch-counter0. Идентичность model/run и точный законченный slice
  проверяются; следующий advance снимает hold. При сходе с ленты
  обычная анимация продолжается; скорость50, запуск30, физика и часы
  анимации не заморожены. Это общее исправление F4, без привязки к комнате.

Проверка — статический разбор ROM/кода, необходимая генерация без диагностики
и инкрементальная Release-компиляция. Игра, тесты, CPU checks, renderer/GPU
агентом не запускались. 2026-10-11 пользователь проверил test126, подтвердил
исправления и разрешил коммит/push в main. Старые EXE и данные сохранены,
архивы121/Android006 не обновлены.
