# Test-055: музыка при переходах между сценами

EXE: D:/Games/DoraRecomp3/testbuild/Dora64-3-test-055.exe.
Общий музыкальный канал сохраняет последний запрос новой композиции, пока предыдущая останавливается.
Запуск повторяется после штатного освобождения канала; новая stop-команда отменяет ожидание.
Правка общая для меню, карты, уровней и миниигр в Original/Native.
Включены подтверждённые пользователем исправления аудиозадержки, Сидзуки, двери и цветных шариков.
Сборка по прямой команде пользователя, без тестов и запуска игры/эмулятора/renderer/GPU.
Исправление музыки в игре ещё не подтверждено. Прежние EXE/ROM/settings/saves/DLL сохранены.
Подробности: docs/music-handoff-after054.md. Диагностика MUSIC request/defer/stop/resume находится в runtime.log.
