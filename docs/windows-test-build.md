# Windows test-122

В Manual FPS общая кнопка B игрока1 теперь сначала проходит исходный выбор
контакта/NPC (BB080 → DD8FC), затем разрешается непрерывному обработчику
игрока на границе C8B28. Это сохраняет приоритет разговора перед оружием
для всех14 оружий, включая секретные и режимы press/hold/release-charge.
Другие кнопки и игроки сохраняют прежнюю обработку. Original не меняется.
Команда B может ждать ближайшего исходного обновления (20/30Гц); движение,
анимация и полёт снаряда продолжают рассчитываться на Manual FPS.

исходных кадрах. Отрыв цепочки, столкновения и удаление остаются исходными.

в оригинальной функции8002A844. Исходные тайлы/текстуры не меняются.

из-за удержания движения или дрейфа геймпада. При открытии подавляются только
уже удержанные навигационные органы до их отпускания; новые нажатия, мышь
и тач доступны сразу. Блокировка при явном назначении кнопки сохранена.
