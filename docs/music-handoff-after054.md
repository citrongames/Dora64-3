## Общая причина по исходным инструкциям

Общий резидентный dora3_music_request_bank_800442B0 сначала проверяет
801AA680==1, затем трактует ID<4 как остановку. Для обычного bank>=4 читает
единственный BGM handle800DAD28; ветка800442F8 сразу возвращает при ненулевом
handle. Запрос нигде не сохраняется и повторная попытка не назначается.
При нуле настоящий loader80044120 загружает банк в общий buffer8008C230,
80047758 создаёт голоса/sequence и сохраняет новый handle в800DAD28.

Остановка dora3_music_stop_with_fade_80044330 вызывает80048184. Она отмечает
соответствующие voices на затухание/остановку; slot800DAD28 не очищает.
Даже stop duration0 означает отложенную обработку, а не синхронное освобождение.
Slot очищает dora3_sound_handles_collect800446C0 только после80048304==0:
все голоса с этим handle завершились. Сборщик вызывается из общего Source tick
80030894 ->8004281C независимо от Native presentation.

Поэтому новый scene init может попасть между stop и collect: одноразовый
запрос пропускается, старый канал позже освобождается, новая музыка не стартует.
Нельзя просто обнулить slot при stop: прежние voices ещё читают общий buffer,
и загрузка следующего банка повредит их данные. Нельзя ждать в busy loop:
аудиопотоку надо дать обработать остановку.

Caller scope общего запроса: menus/map/save, world room loader801B9954,
script command801DE170, demo/audio menu и миниигры. Save/menu init801C0CC0
однократно запрашивает bank4; map init801BB704 — bank15(hex), другие menus
используют12/13/16(hex). Исправление не привязано к scene id, экрану или FPS.

## Изменение

src/audio_music_handoff.cpp сохраняет один последний запрос при занятом BGM
slot. После штатного полного collect, когда slot действительно обнулён,
повторно вызывает исходный bank loader/start через копию recomp_context.
FPR self pointer исправляется существующим copy_recomp_context; guest stack
остаётся ниже кадра сборщика, его сохранённые регистры/return address не меняются.
Запрос потребляется до DMA yield, чтобы не запускаться повторно.

Новый request заменяет отложенный. Stop, ID<4, audio init и disabled gate
отменяют отложенную команду, чтобы не включать музыку старой сцены позднее.
Сама остановка, её длительность, Original start/DMA/voice registration сохранены.
SFX handles и SDL PCM queue не менялись; аудиоправка051 сохранена.
В журнал добавлены MUSIC request/defer/stop/resume с bank/handle для следующего
пользовательского запуска; нет фонового опроса или логирования каждый кадр.

tools/audio_music_patches.py закрепляет полные ROM hashes и инструкции пяти
hooks: init80044164, request800442B0, busy800442F8, stop80044330,
после collect80044778. Подключён через generate_startup и receipt inputs.
Смысловые имена запроса/остановки добавлены в каталог с прежними ABI aliases.
Зависимости и генерируемые игровые тела вручную не редактировались.
