## Обнаруженный общий дефект

В src/native_texture_animation.cpp observer dora3_native_texture_channel_clock
возвращался не только при построении дополнительного кадра, но и при любом
active_simulation_slice. При этом настоящее тело Original bitmap updater
80028C74 продолжало менять index/delay в Native simulation на конце полного
тика: generated entry guard dora3_native_simulation_tick_end отсекает только
неполные срезы. В world actor tail801E8E68 этот updater вызывается для slots2..7;
аналогичные вызовы есть у снарядов/других actor families и overlays.

После Source/UI фазы фейда канал может иметь ненулевой ChannelClock.age.
Возврат gameplay в Native переставал обновлять этот age, хотя реальный bitmap
index продолжал меняться. Для распознанного полного scroll cycle binder берёт
age, затем вычитает offsets[index]. Это вычитание компенсирует фазу выбранного
bitmap: при застывшем age итоговая текстура неподвижна даже при движении index.
Если updated_epoch устарел, добавочная source_phase также равна нулю.
До первого наблюдения age==0 binder использует текущие index/delay; reset/новое
создание канала возвращает этот путь. Это объясняет зависимость от handoff и
восстановление после пересоздания, а не от самого белого цвета фейда.

## Исправление и охват

Observer теперь исключает только active render frame. Настоящие завершённые
bitmap ticks учитываются при обоих владельцах времени. Constructor boundary
также сбрасывает clock при Native создании/повторном использовании handle,
в том числе при совпадении sequence pointer. Входы/выходы observer остаются
парными; до них generated guard возвращает из неполного simulation slice.
Original active/clamp flags, delay, index, Source скорость и authored assets
не меняются. Draw/private frame остаётся исключённым. Возраст полного цикла
продолжается вместо постоянной компенсации старой фазой. Изменение общее для
bitmap каналов, без исключения по scene ID, типу стрелки или цвету фейда.

Статический поиск ChrNameYajirusi544 привёл к descriptor801FC5F0 и ресурсам
bank0:07CE GIMO/07CF HIT. Его собственные callbacks801EAF58/60 пустые, в этом
constructor нет bitmap channel. Поэтому один лишь label544 не устанавливает
identity видимой пользователю анимированной стрелки; индивидуальный объект
не объявляется воспроизведённым. Исправлен доказанный дефект общего observer,
совпадающий с описанным порядком появления симптома. Визуальное подтверждение
остаётся за пользователем на следующем билде.
