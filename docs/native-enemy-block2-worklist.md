# Рабочий объём всего блока 2

Test042 был промежуточным состоянием первой группы. Test043 включает весь
выбранный блок врагов и активного AI.
Общий CPU pre-build и следующий EXE запускаются только после всего блока:
обычных семейств, связанных частей/генераторов/снарядов и семи семейств боссов,
с понятными именами, комментариями и обновлёнными документами.

Каталог привязан к фактическим actor descriptors и ROM overlays. Все218
типов реализованы и включены в Native ownership; Original остаётся исходным.
Реальные constructor/contact/update функции разрешены в строгой проверке
1168 Source bodies. Ранний unresolved inventory остаётся историческим файлом.
Повторение RAM адреса в разных overlays не объединяет их обработчики.
Общий статус проверок: [coverage](native-enemy-fixture-coverage.md).

Новые замечания пользователя по 042: пауки и их снаряды, взлёт лесной птицы,
летучие мыши выглядят с меньшим FPS, чем выставлено в Manual; большой
механический кролик сильно трясётся при приземлении в лесу фей после города.
Причина тряски при приземлении пока не подтверждена. Supaizan/Batti/Oppi
отсутствуют в Native списке042; теперь их реализация добавлена в основной код
и вошла в043 после полной CPU проверки блока. Связь визуальных названий с конкретным
kind пока не подтверждена; замечание по кролику остаётся открытым.
По Pyonger2 короткая проверка показала24 реальных приземления без обратных
скачков/проникновения под пол и1776 стабильных подшагов на земле. Это
синтетическая CPU проверка; соответствие визуальному кролику и результат
в настоящем лесу фей ещё не установлены.

Все пункты реализации и внешние связи завершены; общий CPU прогон выполнен
перед Windows build043. Игра, окно, renderer/GPU локально не
запускаются. Прежние отчёты PASS042 относятся только к прежним входам.
