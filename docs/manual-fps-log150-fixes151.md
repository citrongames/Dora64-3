Test149 отвергнут пользователем: все первоначально сообщённые симптомы остались.
Test150 был диагностическим; сборка151 содержит перечисленные правки.

## Разбор маркеров и изменения

1. Гонки,32.521/41.122s (segments2/3): при B Native RACE_MATH для
   worldX/Z записывает delta/next=NaN; Source XYZ держатся между Source
   обновлениями, хотя камера меняется. ROM1961B0, stores7630/7680 вычисляют
   brakeC=brake10², это Derived. Ошибочная Motion-рекурсия с retention0
   отравляла проецируемую скорость. Исправлены роли двух stores и общий
   guard: независимое от самого поля присваивание не является его рекурсией.
   Общий Source путь обслуживает обычный и зимний варианты; клип, B, стенки,
   события и правила гонки остаются Source. Игровое подтверждение ожидается.
2. Слизень Boss5,415.409/424.841s (segments4/5): state6/phase2 имеет
   физическое уравнение поворота и не имеет уравнения видимого yaw.
   Store80220474 копирует f2=ПРЕДЫДУЩИЙ physical heading в actor+10
   в delay slot перед новым поворотом2091C. Добавлен ROM-qualified hook,
   копирование завершённого предыдущего пути с проверкой lifetime и обоих
   Source endpoints. Оригинальное запаздывание копии на один Source шаг
   сохранено; эффект447 использует математический путь родителя из149.
3. Комната финального Boss7,490.415/495.572s (segments6/7): scene311,
   world70A50, boss overlay11D570/types472–477. Пользователь уточнил:
   рамка/полоса, прозрачный центр, плавный тёмный низ, привязка к экрану.
   Исправление этого слоя ПОКА НЕ УСТАНОВЛЕНО. Проверены оба варианта,
   Source room descriptor, банк50/id321 (placement), реальные GIMO bank51
   ids1244/1239/1241/1240/1242, Boss7Wall2131 и общие экранные draw пути.
   Не следует принимать bank51/id321 за геометрию этой комнаты: descriptor
  321 сначала выбирает placement из bank50 и тот ссылается на другие модели.
   В150 DL reader пропускал середину списка и не разрешал segmented DE;
   записи роли bitmap также делили один бюджет. В151 чтение включает
   RSP segment bindings, nested lists, vertices/hash/RGBA, colors/combine,
   texture tiles и projection. Это наблюдение реально созданного списка,
   без самостоятельного renderer/эмулятора. Нужен свежий маркер в комнате.
4. Небо,558.035/560.973s (segments8/9): world room355, script planes
   Endbg11/12 (types202/203), GIMO4B7/4B8. Расширены только X и S двух
   точных ROM vertex arrays, в неизменяемой копии. Облака сохраняют Source
   mirrored repeat и плотность; дальний фон сохраняет Source clamp края.
   Город, наземный mesh4B6, Y/Z, цвет, скрипт и коллизии не изменены.
5. Езда машины,570.491/574.238s (segments10/11): уже scene34/ROM635C0,
   callbacks24A4/267C; world script374 здесь не работает. Native UI
   вычислял машину24C8, но не её шесть зависимых пассажиров. Добавлены
   чистые offset copies C1874 для XYZ пассажиров и совместное построение
   матриц, с возвратом временных полей после draw. Clip/sprite события не
   повторяются, остаются в настоящем Source callback.
6. Полёт вперёд,635.908/637.307s (segments12/13): тот же путь машины
   и пассажиров, исправлен вместе с5; Source flightZ+=12 и bob cadence
   продолжаются существующим Native UI вычислением.
7. После fade,650.157/651.407s (segments14/15): настоящий shutter
   scene34/801C22C4, четыре F6 чёрных прямоугольника с growth69EC,
   viewport/scissor30,30..166,133. BDAF0 из149 был другим переходом.
   Новый ROM-qualified scope26 помечает именно этот shutter STRETCH,
   как его частичное перспективное окно. Source счётчик закрытия сохранён.
