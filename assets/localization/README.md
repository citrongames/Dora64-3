# Языки Dora64-3

Язык выбирается в Game > Language. Доступны японский оригинал, английский и русский.
Настройка сохраняется; без сохранённого выбора используется язык системы.
Уже открытый диалог/сценарий заканчивается на прежнем языке. Меню и спрайты
переключаются сразу. Файлы читаются при запуске; после их редактирования перезапусти игру.

## Структура

- `languages.json` — код папки и название языка в PC-меню.
- `dialogue_font.bmp/json`, guide и aseprite — общий авторский шрифт из Dora64.
- `dialogue_index.json`, `game_text_index.json` — стабильные ID, адреса и ограничения.
- `dialogue_pages.json` — найденные последовательности ID для проверки буфера страниц.
- `scripts.json` — границы оригинальных сценариев.
- `<code>/dialogue.json`, `game_text.json` — ID и перевод без японского оригинала.
- `<code>/choices.json` — восемь парных знакомест ответа Да/Нет.
- `<code>/textures/*.png` — графические надписи в исходных размерах.
- `texture_index.json` — идентичность ROM-картинок, размеры, специальные области.

Добавь язык в манифест и создай папку. Пустая, слишком длинная строка, неизвестный
символ или изменённые команды оставляют оригинальную запись. Отсутствующая PNG
оставляет оригинальную картинку. Повреждённый языковой пакет не отключает другие.
Шрифт сейчас общий для пакетов: набор Latin/Cyrillic из donor atlas. Другой алфавит
требует добавить глифы в общий атлас и JSON, не менять игровые адреса.

В отличие от Dora64, PNG привязаны к целому ресурсу до разбиения на полосы, а не к
RT64-хэшу. Поэтому здесь не нужен `rt64.json`; переключение и структура папок общие.
PNG обязаны иметь размеры из индекса. Экспорт: максимум240 цветов (с запасом для
частичного наложения на оригинальные панели), прозрачность альфа. Не увеличивай
разрешение и не меняй aspect. Готовые PNG не генерируются при запуске игры.

## Правка текста

Сохраняй команды и их порядок: `{white}`, `{red}`, `{yellow}`, `{blue}`, `{next}`,
`{end}`, `{close}`, `{wait}`, `{choice}`, `{yes:N}`, `{no:N}`, `{jump:N}`, `{cursor}`.
Это управляющие байты игры, а не переводимые слова. Один cell — два латинских или
кириллических знака. Цветовой разрыв завершает пару; нечётная половина дополняется
пробелом. Предел находится в `max_cells`. Не добавляй переносы внутри записи:
игра использует собственные таблицы строк. Контекстные `ctx_...` записи описаний
важнее общих `rom_...` фрагментов при соответствующем выводе.

`tools/localization_catalog.py --rom PATH --report REPORT` извлекает локальный
`extracted_source.json` и статически проверяет перевод. `*_source.json` содержат
японский текст из твоего ROM, игнорируются Git и не входят в упаковку.
Это анализ файлов, не запуск игры. `tools/generate_localized_art.py` воспроизводит
пиксельные подписи и нативные экспорты из сохранённых шрифтов/рисунков; нужен Pillow.

Принципы: сохранять характер реплик, короткие естественные инструкции и единые
названия предметов. Шутки адаптировать без изменения сюжетного смысла. Инопланетные
символы до получения переводчика сохраняются намеренно. Полное прохождение для
проверки контекста и показа текста ещё необходимо.
