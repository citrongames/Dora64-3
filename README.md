# Dora64-3 — исследовательский этап

Отдельный локальный проект нативной рекомпиляции **Doraemon 3: Nobita no Machi SOS!**
для Windows, Linux и Android. Vita отложена. Готового игрового порта/APK пока нет.
Windows test-004: ограниченный старт, проверка картинки у пользователя;
[инструкция и ограничения](docs/windows-test-build.md).

Проверенный ROM: Japan, N3DJ, revision byte 0, big-endian z64, 16 МиБ.
SHA-256: `410f99bdd58795639da272c9be9d1ab8c35b61f24f7c1fb92f7e83e1069a2602`.
ROM читается с указанного пользователем пути, не копируется в проект и не изменяется.

Уже выполнено:

- Изучены актуальный Dora64 `680d81feb4c57309ba80536300d73725ea9dffaa`, сборка,
  генератор, патчи, регистрация и все шесть обязательных Android-документов.
- Исправленные зависимости зафиксированы и независимо размещены в `build-deps/`.
- Воспроизводимая проверка ROM, 14 явных загрузчиков оверлеев, разбор 3129 записей LZSS.
- Boot-probe исполняет оригинальные начальные инструкции ROM нативно на Linux/Windows;
  Android ARM64 probe собран, не запускался на устройстве.
- Оригинальный декодер рекомпилирован; 11 выборочных записей совпали побайтно
  с восстановленным Python-декодером после учёта границы PI DMA.
- Диагностический Linux frontend исполняет boot/idle/main/scheduler через
  настоящий N64ModernRuntime. Два аудиобанка прочитаны и проверены побайтно,
  выполнена релокация, завершена инициализация синтезатора, запущен аудиопоток.
- Игра сформировала первые audio/graphics tasks. Одна настоящая аудиозадача
  выполнена RSP, её завершение получил планировщик, в callback переданы
  512 стереокадров начальной тишины на раннем диагностическом этапе.
- Собран RT64 replay: первая F3DEX2 display list обработана на RTX2060/Vulkan
  в WSL. Это отдельная задача из снимка, не живой игровой renderer.
- Подключён живой исследовательский RT64 на Linux: исполнены два оверлея scene34,
  инициализация, update и draw. Пройден startup EEPROM16k;11 ресурсов совпали
  с независимым декодером.32 graphics tasks обработаны, пользователь увидел
  штатный экран просьбы подключить контроллер.
- Отдельно найден, сгенерирован и скомпилирован звуковой RSP-код третьей игры.
  Загруженный текст проверяется побайтно перед исполнением в runtime.

**Текущее состояние:** пакетная генерация1520 original functions и44 SDK
mappings, включая вступление и общий оверлей меню. В test-003 пользователь
подтвердил звук, музыку и3D-вступление без замеченных искажений. Переход к
титульному меню остановился на незарегистрированном801C0CC0. Test-004 добавляет
связанные callbacks/функции меню и запись EEPROM. Меню, сохранения и устойчивость
полного игрового цикла пока не подтверждены.
Все новые candidate boundaries обозначены в карте; число compiled functions
не является процентом готовности. Игру агент не запускает, тестирует пользователь.
